# Divy-Drishti — release documentation

Everything needed to take Divy-Drishti through Google Play submission. Start with
the readiness report; use the rest as you fill in each Play Console section.

| File | What it is |
|---|---|
| `RELEASE_READINESS_REPORT.md` | Full audit: changes made, security / a11y / privacy / permission audits, build result, all remaining issues by severity, release recommendation. **Read first.** |
| `PLAY_PRESUBMISSION_CHECKLIST.md` | Tick-list covering build, signing, Console content, store listing, functional verification. |
| `PRIVACY_POLICY.md` | Privacy policy text — host at a public HTTPS URL, insert a contact email. |
| `PLAY_DATA_SAFETY.md` | Exact answers for the Play Console Data safety form. |
| `PLAY_STORE_LISTING.md` | App name, short/full description, graphic-asset requirements. |
| `PLAY_CONTENT_RATING.md` | Answers for the content-rating questionnaire. |
| `PLAY_APP_CATEGORY.md` | Category recommendation (Tools) with reasoning. |
| `PLAY_CONSOLE_DECLARATIONS.md` | Every App-content declaration + the text to enter, incl. the Foreground Service declaration. |
| `PLAY_REVIEWER_NOTES.md` | Instructions for Google's review team (no login; how to exercise SOS, camera, speech). |
| `OSS_LICENSES_AND_MODELS.md` | Open-source notices + ML model weight license verification (issue H3). |
